# Duelo Arcano — UI asset status (manifest)

UI-01 deliverable (`DUELO_UI_UX_ENHANCEMENT_PLAN.md` §3 "Handoff"). One row per art key of the live catalog
(`CardDef.art`) and per skin slot. **Status** is `registered` only when the key is in `CARD_ART_FILES` / `SKIN_FILES`
(`src/components/cards/skin/assets.ts`) and the file passes `skin/assets.test.ts`; otherwise `missing` (the placeholder
is drawn). `skin/assets.test.ts` fails if this table drops a catalog key or skin slot, lists an unknown one, or its
status disagrees with the registries — update the row in the same change that registers a file.

Columns: key · Spanish name · rarity · tribe (or Hechizo) · element · token · planned phase · status · source recipe
(how the file was produced; `—` until it exists) · quality notes (visual review findings, not automated checks).

**Coverage:** card art **80/80** registered — full catalog, enforced by the UI-06 gate test (UI-03 pilots + UI-04 + UI-05 + UI-06 waves, 2026-11-13; 1 327.0 KB total, the 26 UI-06 spells 393.5 KB / 7.5–26.8 KB each, largest file overall `skeleton-king` 30387 B) · skin **10/10** registered (UI-02, 2026-11-13; total skin output 25.7 KB,
largest file 4.6 KB).

**UI-10 audit (2026-11-13):** 80/80 art + 10/10 skin registered and passing the SVG contract test; all 80 compared on
one 64px contact sheet (no clone-like silhouettes) and the six premium artworks at 220px with both crop windows
(focal masses inside); in-app "Galería de arte" loads 160 thumbnails/crops with 0 broken images; every screen of the
QA run had 0 broken images and 0 emoji. No art file changed in UI-10 — the per-key quality notes below remain the open
art polish list (darkest at 64px: `shadow-stalker`, `venom-spider`, `necromancer`; busiest: `golem-forge`, `ursaria`).
